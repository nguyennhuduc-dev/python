# Python Learning Roadmap

Lộ trình này chia việc học thành các chặng nhỏ. Nên hoàn thành bài tập thực hành ở mỗi chặng trước khi chuyển sang phần tiếp theo.

## 1. Python Fundamentals

- [ ] Cài đặt Python, VS Code và chạy chương trình đầu tiên.
- [ ] Biến, hằng số và quy tắc đặt tên.
- [ ] Kiểu dữ liệu: `int`, `float`, `str`, `bool`.
- [ ] Toán tử và biểu thức.
- [ ] Rẽ nhánh `if / elif / else`.
- [ ] Vòng lặp `for`, `while`.
- [ ] Hàm, tham số, giá trị trả về và phạm vi biến.

**Bài tập gợi ý:** máy tính đơn giản, kiểm tra số nguyên tố, bảng cửu chương, xử lý chữ số.

## 2. Data Structures

- [ ] String và các phương thức xử lý chuỗi.
- [ ] List, Tuple, Set và Dictionary.
- [ ] Slicing, comprehension và thao tác dữ liệu.
- [ ] Stack, Queue và các bài toán tìm kiếm/sắp xếp cơ bản.

**Bài tập gợi ý:** quản lý danh sách sinh viên, thống kê tần suất từ, quản lý kho sách.

## 3. Functions, Modules and Files

- [ ] Hàm có tham số mặc định và keyword arguments.
- [ ] Lambda, map, filter và zip.
- [ ] Module, package và cách import.
- [ ] Đọc/ghi file văn bản, CSV và JSON.
- [ ] Xử lý ngoại lệ bằng `try / except / finally`.

## 4. Object-Oriented Programming

- [ ] Class, Object và Constructor.
- [ ] Instance attributes và class attributes.
- [ ] Encapsulation.
- [ ] Inheritance.
- [ ] Polymorphism.
- [ ] Abstraction và composition.

**Mini project:** quản lý sinh viên hoặc quản lý thư viện bằng OOP.

## 5. Advanced Python

- [ ] Iterator và Generator.
- [ ] Decorator.
- [ ] Context Manager.
- [ ] Type Hints nâng cao.
- [ ] Virtual Environment và quản lý package.
- [ ] Logging và cấu hình ứng dụng.

## 6. Testing and Code Quality

- [ ] Viết Unit Test với `unittest`.
- [ ] Kiểm thử dữ liệu biên và trường hợp lỗi.
- [ ] Đọc traceback và gỡ lỗi bằng VS Code.
- [ ] Tuân thủ PEP 8 và viết Docstring.
- [ ] Tự động chạy kiểm thử bằng GitHub Actions.

## 7. Mini Projects

- [ ] Ứng dụng quản lý sinh viên.
- [ ] Ứng dụng quản lý thư viện.
- [ ] Ứng dụng quản lý chi tiêu cá nhân.
- [ ] REST API cơ bản.
- [ ] Ứng dụng đọc/ghi dữ liệu với SQLite.
- [ ] Dự án xử lý dữ liệu hoặc AI/ML nhập môn.

## Cách học đề xuất

1. Đọc khái niệm và xem ví dụ ngắn.
2. Tự viết lại ví dụ mà không nhìn tài liệu.
3. Làm bài tập từ dễ đến khó.
4. Kiểm thử cả dữ liệu đúng, sai và dữ liệu biên.
5. Ghi chú điều đã học và commit thay đổi lên GitHub.

> Không cần chạy theo số lượng thư viện. Hãy nắm vững cú pháp, cấu trúc dữ liệu, hàm, OOP và cách kiểm thử trước.
